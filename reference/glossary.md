# Glossary

## Audited Convention

A project-wide mathematical convention that has explicit source notes and fixture coverage.
For Gibbsiq, the most important audited convention is the Ising energy sign, offset handling,
upper-triangle coupling rule, and Gibbs conditional sign in
`reference/08-evaluation/equation-audit.md`.

## Baseline

An independently configured solver or exact method used for comparison. Baselines must use
the same model convention, instance, seed policy, and resource accounting as the THRML-backed
run. A baseline is evidence only when its version, tuning budget, timing, and result are
recorded.

## Binary Quadratic Model

A quadratic objective over binary variables `x_i in {0, 1}`. In this repository, BQM usually
means a dimod-compatible model that may include linear terms, quadratic terms, an offset, and
a vartype. Gibbsiq converts BQM inputs into the canonical Ising IR.

## Block

A set of variables updated together by a sampler. In the Stage 2 THRML runtime, blocks should
be constructed from the Ising graph so that independent-color block updates do not put
directly interacting variables in the same independent update set unless the program performs
a true joint update.

## Boltzmann Distribution

The probability distribution proportional to `exp(-beta * E(s))`. Gibbsiq uses tiny models
with exactly enumerable Boltzmann probabilities to test Gibbs signs and future THRML sampler
frequencies.

## Canonical Ising IR

Gibbsiq's internal model representation. It stores variables, linear fields `h`, upper-triangle
couplings `J`, offset, vartype, source format, deterministic variable order, graph metadata,
and conversion metadata under the energy convention:

```text
E(s) = offset + sum_i h_i s_i + sum_{i<j} J_ij s_i s_j
```

## Chain

One stochastic trajectory through sample space. Multiple chains are used to detect disagreement
that a single trace can hide. Chain diagnostics are warnings about sampler behavior, not
certificates of optimality.

## Degeneracy

The number of distinct states that attain the same optimum. Public benchmark fixtures record
exact degeneracy so a candidate cannot pass by reporting only one scalar optimum without
matching the structure of the solution set.

## Diagnostic Fixture

A synthetic or recorded trace designed to trigger a known sampler-health condition, such as
mode collapse, chain disagreement, no recent improvement, repeated samples, or not enough
data. Diagnostic fixtures test honesty of reporting, not optimization quality.

## Effective Sample Size

An autocorrelation-adjusted estimate of how many independent samples a correlated Markov
chain represents. In Gibbsiq it is an ESS-style health signal. It does not prove convergence
to the global optimum.

## Feasibility

Whether a decoded candidate satisfies the original problem constraints. For constrained QUBO
encodings, feasibility must be checked against the native problem, because a low penalized
energy can still correspond to an invalid solution.

## Gibbs Conditional

The probability used to update one spin given the others. Under the Gibbsiq convention,
`gamma_i = h_i + sum_j J_ij s_j` and:

```text
P(s_i = +1 | s_-i) = sigmoid(-2 * beta * gamma_i)
```

The sign is audited because reversing it samples the wrong energy landscape.

## Ground-Truth Corpus

The small benchmark corpus in `reference/06-benchmarks/fixtures/ground-truth-small.json`.
It is generated by exhaustive enumeration, records seeds and provenance, and is scored by
witness recomputation rather than by trusting reported energies.

## Inspector

The planned reporting layer for `SampleResult` artifacts. It should present topology,
traces, diagnostics, warnings, best states, feasibility, and baseline comparisons while
preserving links to raw evidence.

## Ising Model

An energy function over spins `s_i in {-1, +1}`. Gibbsiq uses Ising as the internal target
for QUBO and BQM inputs because THRML sampling and many optimization benchmarks can be
expressed through spin energy functions.

## Local Field

The field acting on one spin after fixing all other spins:

```text
gamma_i = h_i + sum_j J_ij s_j
```

It determines the single-site Gibbs conditional and is therefore part of the sign audit.

## Mode Collapse

A sampler failure mode where returned samples concentrate on too few states. It can produce
a good-looking best energy while hiding poor exploration. Gibbsiq diagnostics should flag
collapse through diversity and trace evidence.

## Offset

The constant term in the objective. It does not change which state is optimal, but it changes
reported energies and benchmark equality. Dropping offsets during conversion is a hard
evaluation failure.

## Oracle

An independent checker that recomputes objective value and feasibility from the input model
and a witness state. The benchmark oracle rejects scalar claims that are not backed by a
valid witness.

## QUBO

Quadratic unconstrained binary optimization:

```text
minimize x^T Q x, where x_i in {0, 1}
```

Gibbsiq accepts QUBO input and converts it to the canonical Ising IR using the audited
binary-to-spin mapping `s = 2x - 1`.

## R-hat

A between-chain and within-chain variance diagnostic from MCMC. Gibbsiq may use R-hat-style
statistics to warn about chain disagreement over scalar traces. It must not present them as
proof that an optimum has been found.

## Raw Samples

The unaggregated states produced by a sampler. Raw samples are required evidence for
stochastic claims because summaries such as best energy, diversity, and success rate must be
recomputable.

## SampleResult

The result artifact schema for solver output. It should contain samples, variables, energies,
best sample, best energy, traces, diagnostics, metadata, and dimod export support. Stage 1
implements the schema; later stages populate it from THRML runs.

## THRML

Extropic's probabilistic energy-based runtime. Gibbsiq targets THRML as the execution
substrate and supplies the optimization layer above it: model conversion, block construction,
schedule control, trace capture, diagnostics, baselines, benchmarks, and reports.

## THRML Runtime

The planned Stage 2 layer that lowers canonical Ising IR into THRML nodes, factors, blocks,
programs, schedules, seeds, initialization policies, raw samples, and traces. It is the next
implementation target, not current completed functionality.

## Thermodynamic Sampling Unit

Extropic's proposed probabilistic hardware unit for sampling from energy-based models. The
local reference paper and Extropic source material motivate Gibbsiq's THRML-first direction,
but Gibbsiq does not treat Thermodynamic Sampling Unit energy-efficiency projections as
evidence of QUBO optimization speedup.

## Trace

A recorded sequence from a run, such as energy, best-so-far energy, magnetization, violation
count, or distance to best state. Traces are used to diagnose sampler behavior and reproduce
claims.

## Vartype

The variable domain of a model or sample. Gibbsiq distinguishes binary variables
`{0, 1}` from spin variables `{-1, +1}` and records conversions between them.

## Witness

A concrete candidate state, tour, partition, or selection that can be checked by the oracle.
Benchmark claims require witnesses because a reported objective value alone is not evidence.
