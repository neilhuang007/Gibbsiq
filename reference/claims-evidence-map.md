# Claims-Evidence Map

This map separates current evidence from target claims. A claim is treated as established
only when the repository contains code, fixtures, tests, or a primary source that can check
it independently.

| Claim | Evidence | Status |
| --- | --- | --- |
| Gibbsiq is THRML-native optimization infrastructure, not a generic diagnostics package. | `PROJECT_BRIEF.md`, `spec.md`, `README.md`, and `reference/00-roadmap/README.md` define THRML as the execution target and place diagnostics, dimod, baselines, and reports around that path. | Design contract. |
| The internal model convention is fixed: `E(s) = offset + sum_i h_i s_i + sum_{i<j} J_ij s_i s_j`. | `reference/08-evaluation/equation-audit.md` records the convention; `src/gibbsiq/model.py` implements the IR; `test_suite/tests/test_exact_fixtures.py` and `test_suite/tests/test_model_compatibility.py` check small-state energies. | Implemented for Stage 1. |
| QUBO, BQM, and Ising inputs are normalized into one deterministic Ising representation with offsets preserved. | `src/gibbsiq/conversions.py`, `src/gibbsiq/model.py`, and `src/gibbsiq/result.py`; exact fixtures in `reference/08-evaluation/fixtures/exact-small-instances.json`; tests in `test_suite/tests/test_stage_01_core_model_compatibility.py` and `test_suite/tests/test_conversion_scenarios.py`. | Implemented for Stage 1. |
| The single-site Gibbs conditional must use `P(s_i = +1 | s_-i) = sigmoid(-2 * beta * gamma_i)`. | `reference/08-evaluation/equation-audit.md` derives the sign; `reference/08-evaluation/evaluation-framework.md` makes wrong sign a hard failure; `test_suite/tests/test_exact_fixtures.py` checks analytic conditional fixtures. | Audited and fixture-tested. |
| The current repository has completed Stages 0 and 1, while the THRML runtime and later layers remain absent. | `reference/00-roadmap/README.md` records Stage 0 and 1 as complete and Stage 2 as current; `CLAUDE.md` lists the implemented modules and the remaining runtime, diagnostics, inspector, and baseline layers. | Current project state. |
| A THRML optimization runtime must lower Ising IR into THRML nodes, factors, blocks, programs, schedules, seeds, initialization, samples, and traces. | `spec.md`, `reference/00-roadmap/stage-02-thrml-optimization-runtime.md`, `reference/01-architecture/thrml-runtime.md`, and `reference/03-samplers/thrml-optimization-runtime.md` specify the Stage 2 target. | Target claim; not yet implemented. |
| Sampler diagnostics are health warnings, not proofs of optimality. | `reference/08-evaluation/equation-audit.md` cites Vehtari et al. for R-hat and ESS formulas and states their limited role; `reference/08-evaluation/evaluation-framework.md` makes "R-hat as proof of optimality" a failure case. | Design and evaluation contract. |
| Benchmark claims require witness states and independent objective recomputation. | `src/gibbsiq/benchmark_oracle.py` re-verifies candidate witnesses; `reference/06-benchmarks/ground-truth-datasets.md` defines the scoring rule; `test_suite/tests/test_benchmark_oracle.py` covers strict witness behavior. | Implemented for public corpus. |
| The public ground-truth corpus contains small instances with proven optima, not heuristic best-known targets. | `tools/generate_ground_truth.py` exhaustively enumerates Tier A fixtures; `reference/06-benchmarks/fixtures/ground-truth-small.json` stores them; `test_suite/tests/test_ground_truth_exactness.py`, `test_suite/tests/test_ground_truth_generator.py`, and `test_suite/tests/test_benchmark_corpus_integrity.py` verify exactness and reproducibility. | Implemented for Tier A. |
| External benchmark values must be classified by evidence strength. | `reference/06-benchmarks/ground-truth-datasets.md` separates self-generated proven optima from external proven-optimal and best-known sources; primary sources include BiqMac, TSPLIB, QAPLIB, Lucas 2014, and Sherrington-Kirkpatrick 1975. | Documented source policy. |
| Agent-facing evaluation must resist fixture echoing and public-test overfitting. | `reference/08-evaluation/agentic-evaluation-research.md` specifies public tests, blind tests, metamorphic mutations, private diagnostic traps, and witness recomputation; `test_suite/tests/test_metamorphic_rewards.py` covers public reward behavior. | Public structure implemented; blind tests remain external. |
| Version 0 requires a validated THRML-backed tiny Ising run with empirical frequencies checked against analytic probabilities. | `PROJECT_BRIEF.md`, `spec.md`, and `reference/08-evaluation/evaluation-framework.md` state this exit criterion; analytic Boltzmann formulas are recorded in `reference/08-evaluation/equation-audit.md`. | Future Stage 2 evidence. |
| Gibbsiq is the optimization and trust layer above THRML; its durable contribution is independent verification and diagnostics that a hardware vendor cannot credibly own for its own device. The accurate analogy is Ocean/dimod for D-Wave plus ArviZ for Stan/PyMC. | `reference/research-journal/2026-07-01-trust-layer-positioning.md` records the decision; `PROJECT_BRIEF.md`, `spec.md`, `README.md`, `CLAUDE.md`, and `reference/00-roadmap/README.md` carry the framing. | Design position (2026-07-01). |
| The runtime contracts — `SampleResult` schema, diagnostic inputs, and witness-recomputing benchmark oracle — are backend-portable at the architectural level as a hedge, while execution stays THRML-first. | `spec.md` and `reference/research-gaps.md` state the hedge; `src/gibbsiq/result.py` and `src/gibbsiq/benchmark_oracle.py` implement backend-neutral contracts. | Design contract. |
| As of 2026-07, THRML (v0.1.3, ~1.1k GitHub stars) has no hardware backend — all execution is JAX GPU simulation — and Extropic's Z1 (announced Oct 2025 for early access 2026) shows no evidence of general availability. | `reference/research-journal/2026-07-01-trust-layer-positioning.md`; primary sources `https://github.com/extropic-ai/thrml` and `https://extropic.ai`. | Research finding (2026-07-01). |
| No existing QUBO/Ising tool (Ocean/dimod, PyQUBO, OpenJij, Fixstars Amplify, qubolite, MQLib, simulated-bifurcation libraries) ships sampler-health diagnostics, failure flags, or witness-verified benchmark oracles; multiple 2025-26 papers call Ising-machine benchmark standardization an open problem. | `reference/research-journal/2026-07-01-trust-layer-positioning.md` records the survey and sources. | Research finding (2026-07-01). |
| Third-party THRML uptake in H1 2026 skews toward optimization. | `reference/research-journal/2026-07-01-trust-layer-positioning.md`; primary sources arXiv:2601.07792 (portfolio index tracking, Jan 2026) and arXiv:2605.06425 (Max-k-Cut Potts). | Research finding (2026-07-01). |
