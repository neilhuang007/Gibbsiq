# 2026-07-15 - Independent CPU Gibbs And Exact Kernel Verification

## Paper Hook

This work supplies the executable reference-verification layer for the methods section. A
THRML-independent sampler records each conditional evaluation and random draw, while a
separate enumerator checks finite transition kernels and simultaneous empirical intervals
against the exact Boltzmann law.

## Goal And Roadmap Alignment

`Project_GOAL.md` requires ThermoMap to verify ideal small-instance behavior before physical
mapping, non-ideal simulation, and quality-adjusted profiling. `TM-VERIFY-01` implements that
dependency exactly: it adds the CPU Gibbs reference, finite-kernel construction, stationary
law checks, reversibility checks where the schedule promises reversibility, and an
independent-law interval contract. The roadmap therefore required no change.

The equation convention remains

$$
E(s)=\operatorname{offset}+\sum_i h_i s_i+\sum_{i\lt j}J_{ij}s_i s_j
$$

with the audited conditional

$$
P(s_i=+1\mid s_{-i})=\operatorname{sigmoid}(-2\beta\gamma_i)
$$

We recorded the transition and interval definitions as EVAL-EQ-021 and EVAL-EQ-022 before
writing production code.

## Hard-Parts Analysis

### H1. The reference and oracle require separate implementation paths

`reference_sampler.py` recomputes local fields directly from the linear and quadratic
coefficient maps. `verification.py` independently enumerates conditional tables and composes
their matrices. Neither implementation calls `IsingModel.conditional_probability`, and the
kernel verifier never calls the sampler. This separation makes a shared wrong-sign bug less
likely to pass both paths.

The exact kernel cap is eight variables, or 256 enumerated states. The verifier checks the
maximum row-sum/non-negativity residual, the maximum stationary residual, the maximum
detailed-balance residual, strong connectivity, and graph period. The absolute numerical
tolerance is `1e-12`. The two-spin systematic-scan artifact has stationary residual
`9.71445146547012e-17` and detailed-balance residual `0.028410690187546044`; it passes the
stationary and ergodic contract while recording reversibility as unrequired. The identity
trap has zero stationary and detailed-balance residuals but fails irreducibility and the
overall verdict.

### H2. Blocked updates require one conditioning state per independent phase

A user block must cover each variable once and contain no interacting pair. Every spin in a
legal block is conditioned on the same phase-start state, and all sampled spins are committed
together. Systematic phases instead condition each spin on the preceding updated state.
Random-single-site steps choose one position uniformly. The trace records the phase index,
state before, conditioning state, conditional probability, uniform variate, and state after
for every single-site work unit.

### H3. Empirical intervals require genuinely independent retained states

The empirical verifier accepts only `sampling_design="independent_chains"`. It predeclares
spin-up indicators, every pair product, and every exact energy-level indicator. It applies a
Bonferroni correction across all observables and the bounded Hoeffding half-width from
EVAL-EQ-022. Indicator intervals are clipped to `[0,1]`; pair-product intervals are clipped
to `[-1,1]`.

The main evidence run uses seed `20260715`, beta `0.8`, 2,000 independently derived MT19937
chain seeds, and one retained one-spin heat-bath refresh per chain. A one-spin refresh draws
the exact target law regardless of its all-up initial state, so no unmeasured burn-in claim is
needed. The observed up frequency is `0.374`, the exact probability is
`0.36354745971843366`, and the 99% familywise half-width across three comparisons is
`0.039990404021515415`. All three intervals cover their targets. An all-up 2,000-state trap
fails all three intervals.

The sensitivity artifact repeats seeds `9100` through `9104` at 200 and 800 independent
states. All five recorded runs pass at each size. The marginal half-width contracts from
`0.1264607612583459` to `0.06323038062917295`, exactly following the declared inverse-square-
root sample-size scaling. These ten observations are a replay and sensitivity record; they
are not presented as an estimated long-run coverage probability.

### H4. Replay evidence requires stable RNG partitioning and immutable results

Each chain seed is the first 64 bits of SHA-256 over the domain-separated string
`gibbsiq-reference-v1:<master-seed>:<chain-id>`. Each chain owns a separate
`random.Random` MT19937 instance. A fixed seed therefore replays every initial state, chosen
position, uniform variate, transition, retained state, and energy. Result metadata is
recursively frozen; `to_dict()` returns a detached copy. Timing is measured by the artifact
driver rather than stored in the result, because host timings would make equal seeded results
compare unequal.

## Decisions

1. We define one work unit as one single-site conditional evaluation. The main evidence run
   records 2,000 work units, and the two-chain replay test independently checks 16 work units.
2. We retain canonical offsets in total-energy evidence and exclude them from conditionals
   and normalized probabilities. An offset-shift regression verifies identical state and
   interaction-energy traces with the expected total-energy shift.
3. We require exact variable order and plain integer `-1` or `+1` in caller-supplied state
   tables. Boolean and floating aliases fail before matrix verification.
4. Observable identifiers use variable positions. This makes evidence stable when a variable
   label has a process-specific `repr`; the report separately records variable order.
5. We use 99% familywise confidence for the public empirical demonstration. This value was
   chosen before observing the seeded draws and is accompanied by the 200/800 sample-size
   sensitivity record.
6. We use `max_variables=8` and `tolerance=1e-12` for the public kernel gate. The cap bounds a
   dense matrix at 65,536 entries; larger exact verification remains an explicit caller
   refusal rather than an implicit memory allocation.

## Rejected Alternatives

- A shared RNG stream across chains was rejected because changing one chain's work would
  perturb every later chain and obscure independent-restart provenance.
- Python's randomized `hash()` was rejected for seed derivation because it is process-
  dependent. SHA-256 gives a recorded, domain-separated mapping.
- Parallel updates of interacting spins were rejected because their conditional product is
  not the joint heat-bath law.
- A universal detailed-balance requirement was rejected because ordered compositions of
  invariant single-site kernels are generally non-reversible. Stationarity and ergodicity
  remain required.
- Detailed balance alone was rejected as a correctness verdict because the identity kernel
  is a counterexample.
- Rounded exact-law counts were retained only as a deterministic interval arithmetic test.
  They were rejected as the empirical sampler gate; the seeded 2,000-restart experiment is
  the sampler-facing gate.
- Applying Hoeffding intervals to a thinned single-chain trace was rejected because the
  independence premise would be false. Autocorrelation-aware inference belongs to the
  diagnostics track.
- Runtime optimization and vectorization were rejected from this oracle. Its purpose is
  transparent small-state verification, and this task makes no throughput claim.

## Limitations And Follow-Up

The exact verifier allocates dense matrices and is intentionally capped at eight variables.
The empirical intervals cover bounded observables under independent restarts; they do not
diagnose autocorrelation, multimodality, or optimality. The CPU reference establishes ideal
semantic evidence and supplies no THRML, target-hardware, delayed-update, calibration,
throughput, energy, or advantage claim. The non-ideal dynamics and target-aware execution
lanes close those later gaps after their roadmap dependencies are satisfied.
